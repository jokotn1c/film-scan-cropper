FilmCrop 使用说明

FilmCrop 用于自动识别并裁切相机翻拍的胶片画面，支持批量处理、自动转正，以及保留齿孔或边框。

一、经典界面

启动方式：
python film_gui.py

操作步骤：
1. 拖入 RAW、照片或文件夹，也可以点击“添加文件”或“添加文件夹”。
2. 选择输出文件夹。
3. 选择画幅和导出格式。默认自动识别画幅、开启自动转正并导出 16 位 TIFF。
4. 需要保留胶片边缘时，勾选“保留齿孔 / 边框”。
5. 点击“微调”，可调整上下收边、120 边框扩展和 135 留边。
6. 点击“开始裁切”。选中文件可预览结果，双击可打开输出图片。

支持画幅：
135/6x9、6x4.5/半格、6x6、6x7、XPan 6.5x2.4、中画幅宽幅 135 后背 5.6x2.4。

输出文件：
- 16 位 TIFF 或 JPEG。
- 文件名增加 _crop 或 _border 后缀。
- 每批处理生成 CSV 和 JSON 报告。

二、手动裁切界面

启动方式：
python film_gui_modern.py

添加图片后，在预览图上拖出选区，或拖动已有选区的角点进行调整。点击“恢复自动”可重新使用自动检测。选择输出位置与格式后，点击“开始裁切”。

三、命令行

单张图片：
python film_crop.py input.jpg --format auto --output result.jpg

指定画幅：
python film_crop.py input.jpg --format 6x6 --output result.jpg

保留齿孔或边框：
python film_crop.py input.ARW --format auto --keep-border --output result.tif

批量处理：
python film_crop.py scans --format auto --output-dir cropped

查看全部参数：
python film_crop.py --help
